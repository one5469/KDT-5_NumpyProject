# 국내 기상 데이터 분석 — 태풍 발생 및 피해

국내 기상 데이터를 분석한 4인 팀 프로젝트에서 태풍 발생 빈도와 피해 규모 분석을 담당했습니다.

- 기간: 2024.02.21–2024.02.22
- 담당: 권혁원 / 태풍 자료 수집·분석·시각화
- 데이터: 기상청 태풍 통계 및 태풍 피해 집계 자료
- 기술: Python, pandas, NumPy, Matplotlib, SciPy, Selenium, BeautifulSoup

## 담당 작업

- 전체 태풍과 한국에 영향을 준 태풍의 통계를 수집하고 분석용 CSV 구성
- 월별·연도별 발생 빈도와 기간별 평균 비교
- 포아송·지수분포를 사용해 발생 횟수와 발생 간격의 분포 탐색
- 인명·재산 피해의 연도별 변화와 주요 태풍의 지역·시설별 피해 비교
